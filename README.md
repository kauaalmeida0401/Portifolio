## 💻 Como rodar no seu computador

1. Baixe o projeto: clique em **Code → Download ZIP** e extraia a pasta (ou use `git clone https://github.com/kauaalmeida0401/Portifolio.git`).
2. Abra o arquivo `index.html` no navegador.

Pronto! Não precisa de servidor nem de instalação.

## 🎨 Como mudar o nível de uma habilidade

No `index.html`, cada habilidade tem um valor de 0 a 10 em `data-nivel`:

```html
<div class="nivel" data-nivel="6"></div>
```

Troque o número e salve. Os quadradinhos se ajustam sozinhos.
